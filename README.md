# Projeto Monorepo Fullstack

Este repositório adota a estratégia de **Monorepo**, unificando as camadas de frontend, backend e documentação em uma única estrutura de versionamento.

⚠️ **AVISO IMPORTANTE:** Todos os dados, credenciais, cenários e informações manipulados, exibidos ou gerados sob o escopo deste projeto são estritamente **fictícios** e possuem fins puramente didáticos ou de simulação de desenvolvimento.

## Estrutura do Repositório
- `/backend`: Camada de serviços (Java)
- `/frontend`: Interface do usuário (Node)
- `/docs/decisions`: Registro de Decisões de Arquitetura (ADRs)
